MG1CS080 / ZL5CX5A3A2 / F01R0AD4GA — эвристический поиск карт ограничений

Образ TC387QP_flash-20251015-113645-268.bin, 10420224 байт, база 0x80000000. Калибровка 0x900000–0x99B700. Данные (таблицы) адресуются таблицей указателей файл 0x312028 (480 объектов).

0. Что говорят дорожные логи (OBD)

  • MAF упирается в 203–211 г/с во всех WOT-отрезках, независимо от передачи/скорости → жёсткий потолок по воздуху.
  • Наддув 1.19–1.36 бар, MAP абс. максимум 229 кПа.
  • УОЗ на WOT всего 1–7° — воздух есть, момент срезается зажиганием/моментом.
  • IAT 20–47 °C; при холоде машина быстрее → температурозависимый ограничитель.
  • Три тюна 235/240/262 дают одинаковый результат на дороге, но разные на стенде (4-я передача) → кламп момента, не зависящий от карт наполнения.

1. Структура образа

участоксодержимое
0x000020–0x034000FBL (CUBAS bootloader)
0x034000–0x040000идентификационный сегмент
0x040000–0x100000ASW
0x100000–0x600000ASW-код
0x600000–0x900000EMPTY (0xFF)
0x900000–0x960000ASI/скаляры калибровки, строки ZL5CX5A3A2, CX11_AUT_FWD_Ch6b-mon_180Hp
0x960000–0x99B700данные: 480 таблиц/кривых (по указателям 0x312028)
0x9E0000–0x9F0000заполнитель ASCII «PCMFLASH» (след читающего инструмента)

Важно: реальные значения карт — преимущественно int16 (только ~10 объектов float32). Без A2L масштабы неизвестны, поэтому гипотезы строятся по форме, осям и диапазонам.

2. Проверенные кандидаты (я проверил вручную)

Граница максимального момента / torque envelope vs RPM

0x9003B0 (адрес 0x809003B0), f32 1×7, значения 190..385

Кривая 190, 200, 300, 385, 385, 385, 340 (Нм) по оси 0x900390 = 800, 1000, 1450, 2200, 4000, 5300, 6000 об/мин. Пик 385 Нм. Гипотеза: предельный/эталонный момент двигателя по оборотам — один из главных ограничителей момента (сток 325, стенд 412 — потолок 385 как раз посередине).

Карта момента (запрос/лимит) 16×16

0x901274 (адрес 0x80901274), i16 16×16, значения 100..600

Гладкая поверхность 100…600, насыщается в 600 справа (высокая нагрузка). Гипотеза: либо driver demand (педаль×обороты→момент), либо torque limiter (max torque по нагрузке/оборотам). Блокировка значения на 600 говорит о верхнем клампе момента.

Температурная ось и коррекция (IAT/ОЖ)

0x905004 (адрес 0x80905004), f32 1×16, значения 233..383

Ось 233…383 K = −40…110 °C (шаг 10). Вектор 0x905134: 2.0, 2.0, 2.037, 2.01, 1.863, 1.898, 1.932, 1.967, 2.0, 2.04, 2.08, 2.1, 2.16, 2.2, 2.24, 2.3 — провал около 20–30 °C и рост к горячему. Гипотеза: температурная коррекция (топливо/наддув/КПД) — объясняет зависимость «холоднее = быстрее».

Эффективность/конверсия момента (гладкая поверхность)

0x908C64 (адрес 0x80908C64), f32 10×11, значения 0.158..2.85

Поверхность 0.158…2.85, монотонно растёт по обоим направлениям. Гипотеза: коэффициент преобразования/эффективности (топливо→момент) либо многослойная коррекция. Может участвовать в расчёте момента и, косвенно, в ограничении.

Возможный потолок наддува/нагрузки

0x924200 (адрес 0x80924200), i16 8×32, значения 1200..6000

В окрестности много повторяющегося значения 1350 (1.35 бар!) вперемешку с 2000. Гипотеза (слабая): таблица-потолок наддува/нагрузки с базой 1350 мбар, что совпадает с логом 1.19–1.36 бар. Требует точной разметки (ширины) — пока предварительно.

4. Итоговые гипотезы по «защите»

  1. Потолок момента (385 Нм) по оборотам (0x9003B0) — вероятный аппаратный/эталонный кламп. Тюны 235/240/262 упираются в него одинаково.
  2. Карта момента 16×16 с насыщением 600 (0x901274) — driver demand или torque limiter; второй кандидат на кламп.
  3. Температурная коррекция (ось 0x905004, 233–383 K) — объясняет лучший разгон при холоде.
  4. Потолок воздуха/наддува ~1.35 бар (0x924200, предварительно) — совпадает с логом 1.19–1.36 бар.
  5. Внешний момент (TCU/CAN) — по логам момента интерфейсные таблицы 0x900E20 (агент C), перепроверить отдельно; 8AT Aisin сам ограничивает момент.
